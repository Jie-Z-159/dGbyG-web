About

The dGbyG web server is designed to enable the prediction and exploration of standard Gibbs free energy changes (ΔrG°) in biochemical reactions and genome-scale metabolic models (GEMs). Using biochemical reactions as input, the server applies a graph neural network (GNN)-based framework to estimate thermodynamic properties with broad structural coverage. The platform integrates the computational methodology described in "Unraveling principles of thermodynamics for genome-scale metabolic networks using graph neural networks", allowing users to predict ΔrG° at both the single-reaction and pathway levels. In addition to on-demand prediction, dGbyG Web provides access to precomputed thermodynamic annotations across 115 integrated GEMs, enabling rapid exploration of reaction energetics at the genome-scale level without requiring local software installation.

Prediction workflow

The dGbyG computational pipeline is illustrated in the figure above and consists of input preprocessing, metabolite-level prediction, condition-specific correction, and reaction-level aggregation.

In the input stage, users can submit biochemical reactions using multiple identifier types (e.g., SMILES, InChI, KEGG, MetaNetX, HMDB, BiGG, ChEBI, PubChem, or common names), including mixed formats. All identifiers are resolved into standardized molecular structures before prediction. Users can also specify biochemical conditions, including pH, ionic strength (I), pMg, and electrical potential (E).

At the core prediction stage, each metabolite is processed independently using a GNN to predict its standard Gibbs free energy of formation (ΔfG°). Molecular structures are converted into graph representations, where atoms are encoded as nodes and bonds as edges. Atomic number, hybridization, aromaticity, and charge are used as node features, while bond types are used as edge features. These features are embedded and processed through two message passing neural network (MPNN) layers, where information is iteratively propagated and aggregated. Residual connections preserve atom-specific features, enabling the model to capture local chemical environments. The resulting representations are passed through feedforward neural network (FNN) layers, and an additive pooling layer sums atom-level contributions to produce ΔfG° for each metabolite.

Condition-dependent corrections (ΔΔfG′°) are applied at the metabolite level to account for deviations from the reference state (pH 7.0, T = 298.15 K, I = 0.25 M, pMg = 14). These corrections are derived using a pseudoisomer-based Legendre transformation framework. Under non-standard conditions, ΔΔfG′° accounts for changes in protonation, Mg2+ binding, and ionic strength (via the extended Debye–Hückel equation). For multi-compartment reactions, electrochemical contributions are included as Ncharge · F · ΔΨ. Consequently, predictions for non-standard conditions (e.g., in a specific cellular compartment) are calculated as: ΔfG′° = ΔfG° + ΔΔfG′°.

Finally, reaction Gibbs free energies are obtained by stoichiometric aggregation, summing corrected metabolite energies weighted by their coefficients to yield ΔrG°.

Uncertainty estimation

Prediction uncertainty arises from both experimental variability in the training data and model parameter uncertainty. For each reaction in the training set, measurement variability is quantified using a robust variability index (α), which balances reaction-specific standard error (SEM) with global dataset variance, ensuring stable uncertainty estimates even for reactions with limited sample sizes.

Under the assumption of normally distributed noise, we employ an ensemble modeling strategy: 100 perturbed training datasets are generated by sampling noise according to each reaction's α index, and 100 corresponding GNN models are trained. For any user query, the results from these 100 networks are aggregated: the ensemble mean of ΔrG° is reported as the final predicted free energy, while the ensemble standard deviation (SD) serves as the associated uncertainty estimate.

Precomputed thermodynamic data for GEMs

A total of 115 GEMs were processed to generate precomputed thermodynamic annotations. Reaction networks and metabolite data were obtained using COBRApy, and compartment-specific conditions (e.g., pH, ionic strength, pMg, electrical potential) were assigned based on literature and curated databases, with fallback estimates from BioNumbers or related organisms when needed. ΔrG° values were then computed using the dGbyG Python package.

To enable consistent comparison and efficient querying, identifiers were standardized to BiGG IDs wherever possible. All compartment-specific parameters are provided on model pages under “Compartment Conditions”.

Data sources

Training data were integrated from TECRDB and curated datasets of metabolite formation energies. Independent validation used a curated subset of the openTECR database (96 reactions).

The GEM library includes 115 models: 107 from BiGG Models, 7 from the Metabolic Atlas repository, and the latest Recon3D human model.

Benchmarking and validation

dGbyG achieves strong predictive performance. In ten-fold cross-validation, it reached an MAE of 9.18 kJ/mol and RMSE of 25.88 kJ/mol, outperforming eQuilibrator 3.0 (MAE 19.46, RMSE 82.88).

At the genome scale, dGbyG provides broader coverage, predicting 74.63% of reactions in Human1 and 71.22% in Recon3D, compared with 46.26% and 43.45% for eQuilibrator.

Independent validation on 96 openTECR reactions showed full coverage (96/96), while eQuilibrator applied to 67. On the shared subset, dGbyG reduced MAE from 9.66 to 7.19 kJ/mol and RMSE from 20.02 to 13.21 kJ/mol.

The web server is freely accessible and provides API documentation.
